# Stage-2 Anchor Query Quality Figure

This directory contains the reproducibility entry points for the
`anchor_quality_stage2` probe and its layer/head figures.

The model execution logic still lives in `pipeline/stage2_anchor_probe`; this
directory keeps the experiment launcher and plotting code together with the
analysis artifact.

## Run The Probe

From the repository root:

```bash
CUDA_DEVICES="0" \
MODELS="mistral-7b-instruct-v0.2" \
BUDGETS="1024" \
DATASETS="qasper" \
LONGBENCH_SAMPLE_LIMIT=50 \
bash analysis/figure_stage2_anchor_quality/run_anchor_quality_stage2.sh
```

The default output directory is:

```text
analysis/figure_stage2_anchor_quality/out/
```

The expected probe directory for the default command is:

```text
analysis/figure_stage2_anchor_quality/out/longbench/anchor_quality_stage2/1024/mistral-7b-instruct-v0.2/qasper/
```

For a dry run:

```bash
DRY_RUN=1 bash analysis/figure_stage2_anchor_quality/run_anchor_quality_stage2.sh
```

## Plot The Figure

After the probe finishes, run:

```bash
python analysis/figure_stage2_anchor_quality/plot_anchor_quality.py
```

The default output is the paper-oriented single-row figure:

```text
<probe-dir>/plots/paper_anchor_quality_main.{png,pdf}
<probe-dir>/plots/proxy_fidelity.pdf
<probe-dir>/plots/appendix_anchor_cosine_page_recall.{png,pdf}
```

The main figure is intentionally compact:

- panel (a): proxy-query information fidelity. The curve shows signed top-r
  channel recall, and Qout is shown as the horizontal reference at 1;
- panel (b): routing fidelity. The curve shows retained attention mass under
  the true query distribution.

The appendix figure contains the auxiliary metrics omitted from the main
figure:

- panel (a): query cosine similarity;
- panel (b): page recall against Exact-TopK.

The vertical dotted line marks `--ada-split-layer`; it is used only as a visual
cue for the layer after which Qmid and Qin become very close.

Suggested paper caption:

```text
Proxy-query and routing fidelity across decoder layers. Colors denote query
anchors. (a) Qmid and Qin preserve the routing-critical signed top-r query
channels, with Qout shown as the unit reference. (b) The same proxy queries
retain most of the true attention mass. The dotted vertical line marks layer
20, after which Qmid and Qin become nearly indistinguishable.
```

To plot a different run:

```bash
python analysis/figure_stage2_anchor_quality/plot_anchor_quality.py \
  --probe-dir analysis/figure_stage2_anchor_quality/out/longbench/anchor_quality_stage2/1024/mistral-7b-instruct-v0.2/qasper
```

To also generate the exploratory diagnostic plots and head heatmaps:

```bash
python analysis/figure_stage2_anchor_quality/plot_anchor_quality.py \
  --include-diagnostics
```

Figures are written to `<probe-dir>/plots/`, and compact CSV tables are written
back into `<probe-dir>/`.

The plotting script expects these files:

- `stage2_probe_summary.csv`
- `stage2_probe_layer_detail_summary.csv`
- `stage2_probe_head_summary.csv`

These files are generated by the `pipeline.stage2_anchor_probe` metrics step
during LongBench evaluation.
